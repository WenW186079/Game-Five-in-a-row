# Backgammon Web (simple)

Quick local multiplayer Gomoku (Five in a Row) scaffold using Node.js + Socket.IO.

Run locally:

```bash
cd backgammon-web
npm install
npm start
# open http://localhost:3000 and create/join a room
```

To share with friends: run locally then expose port with `ngrok http 3000` and share the generated URL.

This is a minimal prototype: client-side UI and server state are basic and meant to be extended.
